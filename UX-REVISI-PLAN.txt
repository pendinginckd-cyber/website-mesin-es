3. VISITOR COUNTER (PENGUNJUNG HARIAN & TAHUNAN)
================================================================================
Masalah: Belum ada counter pengunjung website
File baru:
  - src/types/visitor-stats.ts
  - src/lib/firestore/visitor-stats.ts
  - src/components/public/visitor-counter.tsx
  - src/components/public/visitor-stats-display.tsx
  - src/app/(admin)/admin/visitor-stats/page.tsx
File update:
  - src/app/(public)/layout.tsx (tambah visitor-counter component)
  - src/components/layout/footer.tsx (tampilkan counter kecil)
  - firestore.rules (tambah rules visitorStats)
Firestore:
  - Collection: visitorStats (single doc, ID: "default")
  - Fields: dailyVisitors, yearlyVisitors, totalVisitors, baseDaily, baseYearly, baseTotal, lastResetDate, lastYearReset
Cara kerja:
  - Setiap user buka website → increment +1 (pakai localStorage agar tidak double count per hari)
  - Auto-reset harian: jika tanggal berubah → dailyVisitors reset ke baseDaily
  - Auto-reset tahunan: jika tahun berubah → yearlyVisitors reset ke baseYearly
  - totalVisitors tidak pernah reset
Admin page:
  - Form set nilai start (baseDaily, baseYearly, baseTotal)
  - Tampilkan counter real-time
  - Tombol reset manual (opsional)
Tampilan publik:
  - Footer: "1.250 pengunjung hari ini" (kecil, subtle)
  - Bisa ditambah section di homepage nanti

11. TAP EFFECT DI MOBILE
================================================================================
Masalah: Tidak ada feedback visual saat user tap elemen di mobile
File update:
  - src/app/globals.css (tambah utility class .tap-effect)
  - Semua komponen interaktif (buttons, links, cards, filters, accordion, dll)
Aksi:
  - Tambah CSS class .tap-effect dengan :active pseudo-class
  - Efek: scale(0.97) + opacity(0.85) saat tap
  - Hanya aktif di mobile: @media (hover: none) and (pointer: coarse)
  - Tidak mengganggu hover effect di desktop
  - Apply ke:
    * Semua tombol (Button component)
    * Link navigasi (navbar, footer, breadcrumbs)
    * Card produk, artikel, video, testimoni
    * Filter buttons (pill buttons)
    * Accordion items (FAQ)
    * Gallery thumbnails
    * Admin sidebar items
    * Toggle switches
Catatan: Efek seperti ripple/press di aplikasi native, meningkatkan UX mobile
