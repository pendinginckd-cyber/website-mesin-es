# Draf Artikel Silo SEO — Mesin Es Kristal Semarang

Draf artikel ini siap **ditempel (paste)** ke Admin → Artikel untuk membuat konten silo yang menargetkan kata kunci "mesin es kristal semarang".

**Alur untuk admin:**
1. Buka `/admin` → menu **Artikel** → **Tambah Artikel**.
2. Isi field sesuai draf di bawah (judul, slug, kategori, tags, excerpt, cover, isi).
3. Pastikan **Pengaturan SEO**: `SEO Title`, `SEO Description`, `Target Keywords` memakai nilai yang disarankan.
4. Publish. Setiap artikel mengarah ke landing `/mesin-es-kristal-semarang` sebagai internal link.
